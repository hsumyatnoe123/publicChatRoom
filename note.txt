=> How to use Vite

1. Install
    npm install --save-dev vite

2. Create a vite.config.js file
    import { defineConfig } from 'vite';
    export default defineConfig({
        root:'./src',
        build: {
            outDir: '../dist', 
        }
    });

3. Update package.json
        "scripts": {
            "dev": "vite",
            "build": "vite build"
  }

4. Run Build the app for production
    npm run build

5. Run Vite in development server
    npm run dev

=> How to install Tailwind Css

1. Install Tailwind CSS
https://tailwindcss.com/
https://tailwindcss.com/docs/installation/using-postcss

npm install tailwindcss @tailwindcss/postcss postcss

2.Add Tailwind to your PostCSS configuration
create postcss.config.js manually ( Note: do not forgot to export as ES6 )

export default {
  plugins: {
    "@tailwindcss/postcss": {},
  }
}

3. Add the Tailwind directives to your CSS
create a css file located to (eg. src/css/main.css)
@import "tailwindcss";

4. include css link to each html files
<link href="./css/main.css" rel="stylesheet" type="text/css">

npm run build 
npm run dev
